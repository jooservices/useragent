# Changelog

## [4.0.0] - 2026-09-09

- Rebuild generation around coherent, checksummed dataset profiles.
- Add deterministic instance-first generation, batch uniqueness, matrix access,
  immutable fluent requests, and a stable non-interactive CLI.
- Remove the archived 1.x template, bot, global state, and class-string APIs.
- Add generator-bound fluent builders, string pools, stable profile identities,
  and complete control-character validation.

The 1.x repository history is archived and is not an ancestor of this rebuild.
